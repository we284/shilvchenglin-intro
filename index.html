智能垃圾分类识别与低碳科普系统

一、项目背景

垃圾分类推行了很多年，学校里也一直在讲。可是真到扔的时候，人还是会站在桶前犹豫：手里这个奶茶杯，到底算哪一类。

问题通常不在态度。宣传材料讲的是四大类，桶身上印的也是四大类。可拿在手里的，永远是某一件具体的东西。四大类的概念记住了，不代表看见一件没见过的东西就能归进去。

市面上已有不少识别工具。多数要把照片传到服务器，有些人就不太愿意用。还有一部分得联网，而垃圾房、地下车库这种地方信号往往不好。

二、做法

这些顾虑，本项目是从架构上解决的，不靠解释去打消。模型随网页下载到手机本地，识别在本机跑。照片不出设备，不上传、不留存，也就不存在泄露的问题；没有服务器，这个风险点本身就不存在。应用也不依赖网络，垃圾房、地下车库这类信号差的地方照样能用。

四种使用方式

  • 拍照识别。对准垃圾拍一张，给出物品类别和投放建议。画面里有几件，就分别识别几件。
  • 实时检测。打开摄像头，画面里的垃圾被实时框出，逐个标注名称和该去的桶。
  • 分类练习。把垃圾拖进对应的桶，攒下的积分能在种植园里种树，树随积分长大。
  • 图鉴。收录 83 种常见垃圾，每认出一种收录一条，附上该类垃圾的说明和去向。

还有一件事：挑战赛

系统随机点名一种垃圾，让人去现实里找到它、拍照、识别，认对了才算通过。这一条同时也是效果检验：练习里记住的分类，到了真实场景还认不认得出，看前后正确率的对比就知道。

应用面向学生群体。如果每次扔垃圾都要打开应用查一遍，它就只是个查询工具，关掉之后什么也留不下。所以做了练习、图鉴和挑战赛：让人在反复使用中把分类记牢，练到不用查也能分对。

三、技术方案

识别分两步。先用 YOLOv8n 找出画面里有哪些物体、在什么位置，再把每个物体单独裁出来，交给 MobileNetV3-Small 做 200 类细分类。整图直接识别时，物体占的面积小，容易被背景带偏。先定位再识别，等于先把背景去掉。

工程上有三处花了比较多时间。

  • 体积。最终模型 6.9 MB，单张推理约 25 毫秒（CPU，ONNX Runtime Web），放在手机上可以接受。
  • 置信度。训练时用了标签平滑，概率整体偏平，同样的 70 % 在不同模型上并不是一回事。改用温度缩放做校准，在 1,882 张验证集上重新拟合温度（T=0.75），校准误差从 0.144 降到 0.024。
  • 下载。国内网络下单个源常常中断或者限速，改成多源轮换加断点续传，每个文件都做字节校验，弱网下也能完整加载。

五、项目信息

项目名称拾绿成林 · 智能垃圾分类识别与低碳科普系统
技术栈原生 HTML / CSS / JavaScript + ONNX Runtime Web
核心模型MobileNetV3-Small（分类，200 类）/ YOLOv8n（检测），浏览器本地推理
数据来源训练数据来自 HuggingFace 公开数据集 fritz1024/garbage-classify-with-chinese（中文垃圾分类图片集，限非商业科研/教学用途），按类别均衡抽取 200 类共 19,566 张（训练 17,684 + 验证 1,882，验证集不参与训练，模型准确率即在它上面测得）。分类网络为 torchvision ImageNet 预训练的 MobileNetV3-Small，检测网络为官方 COCO 预训练的 YOLOv8n（未在垃圾数据上微调）
模型准确率一级四类准确率 88.5 %；细类 top-1 准确率 66.4 %（1,882 张验证集，含新增的 20 类）
